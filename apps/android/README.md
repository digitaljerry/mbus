# MBus for Android

Later. Until then, Android users can install the web app (Add to Home screen); it supports
reminders, the live map and everything else in the Web column on the [About page](https://mbus.vercel.app/about).

Like the Apple app, it will use only the MBus API in `apps/web`. Whether it is native Kotlin
or shares logic with iOS via Kotlin Multiplatform is decided when work starts.
